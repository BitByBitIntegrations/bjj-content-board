# Project Documentation Skill

After every /init and /sybau task, maintain a PROJECT.md in the project root.

## On /init (new project)
Create PROJECT.md with:
- **Project Name** — what it is in one line
- **Purpose** — what problem it solves
- **Tech Stack** — framework, language, database, hosting
- **Architecture** — how the system is structured
- **Features** — empty list to be filled as features are built

## On every /sybau task
Append to the Features section:
- Feature name
- What it does
- Key files changed
- Any notable decisions made
